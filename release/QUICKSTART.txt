Codex SelfHeal — Windows 启动修复工具

如何使用
1. 将 ZIP 压缩包完整解压到一个可以写入文件的文件夹。
2. 保留文件夹里的全部文件，不要在压缩包内直接运行。
3. 正常退出 Codex，保存好进行中的工作。
4. 双击 Codex-SelfHeal.cmd，按终端中的中文提示等待检查或修复。
5. 结束后会显示结果和日志路径，按任意键关闭终端。

不需要安装 Git、Python 或 Node.js，也不需要以管理员身份运行。
不要只下载或移动一个 .cmd 文件，它需要旁边的三个 .ps1 文件。

适用范围
用于 Windows 上已安装的 Codex，在运行环境部署不完整、启动后没有窗口等特定情况下辅助修复。
使用系统自带的 Windows PowerShell 5.1，需要能够查询当前用户注册的 Codex 应用包。
不支持 macOS、Linux，也不能保证修复所有“无法启动”问题。
这是个人维护的辅助工具，不是 OpenAI 官方产品。

运行中会发生什么
- 检查安装信息、相关进程和运行环境文件。
- 满足条件时复制并校验运行环境，在终端显示单条进度条。
- 在安全条件满足时清理遗留临时目录和多余副本。
- 尝试启动 Codex，并显示窗口或前端的检测结果。
- 发现活跃后端或正在进行的任务时，可能推迟修复，请正常退出 Codex 后再试。

日志与数据
日志默认位于本工具文件夹里的 logs\self-heal.log。
如果所在文件夹不可写，请将工具移到其他可写文件夹后重试。
工具无需安装，不注册后台任务；删除此工具文件夹即可移除工具及其本地日志。
Codex 必须使用的运行环境与备份仍保存在 Windows 当前用户的应用数据目录，不能随工具任意搬走。
清理会保留当前环境、最近一个旧环境和最近一份备份，不清理聊天记录、用户配置或项目文件。

遇到问题
先保留终端显示的结果，再查看日志。向项目反馈时请检查并隐去日志中的个人路径等信息。
