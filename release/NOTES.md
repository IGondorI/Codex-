## 下载与使用

请下载下面 Assets 中的 **Codex-SelfHeal-v1.2.0-windows.zip**，完整解压后双击 **Codex-SelfHeal.cmd**。

ZIP 内包含运行所需的四个脚本和中文“先读我”说明。无需安装 Git、Python 或 Node.js，无需管理员权限。普通用户无需下载 GitHub 自动生成的 Source code 源码包。

## 本版内容

- 对符合条件的 Codex 运行环境部署故障执行复制、长路径补齐和全文件 SHA-256 校验。
- 中文终端提示及单条原生进度条；长文件路径单行省略，降低频繁刷新导致的闪烁。
- 日志默认保存在解压文件夹内的 `logs\self-heal.log`，结束时始终显示日志位置。
- 支持中文和空格目录，并防止不同脚本副本并发修复同一运行环境。
- 在安全条件满足时清理遗留临时目录和多余备份。

## 适用范围

仅用于 Windows、Windows PowerShell 5.1 和受支持的 Codex AppX/MSIX 安装布局。这是社区辅助工具，不是 OpenAI 官方产品；不能解决所有无窗口故障，也不会修改 Codex 自身的更新机制。

使用前请保存工作并正常退出 Codex。完整解压后再运行，不要直接在压缩包中运行。日志随工具目录保存，但 Codex 必需的运行环境仍位于当前用户的应用数据目录。

发布附件同时提供 `.sha256` 文件，供需要核对下载完整性的用户使用。
